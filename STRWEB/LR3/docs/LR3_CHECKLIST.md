## Важные детали задания

Формула варианта 1 прочитана с изображения на странице 10 PDF:

```
ln((x + 1) / (x - 1)) = 2 Σ[n=0..∞] 1 / ((2n+1) x^(2n+1)), |x| > 1
```

`logarithmSeries` возвращает сумму, число членов n и `Math.log`.
Хвост ограничивается геометрической прогрессией; суммирование прекращается,
когда оценка хвоста ≤ ε. Диапазон не пересекает [-1, 1], максимум 201 точка,
100000 членов на точку. Проверены положительная и отрицательная ветви.

Необычное условие URL выполнено буквально: адрес фото начинается с http(s) и
заканчивается .php/.html. Такой адрес должен отдавать изображение, иначе показан
локальный логотип. Исходные 10 фотографий сотрудников — локальные JPG из LR2;
это ограничение относится к форме добавления, а не к ранее сохранённым данным.

Новый контакт не создаёт учётную запись и не получает выдуманную дату рождения:
`Employee.user` и `birth_date` теперь необязательны. Существующие аккаунты и
проверка совершеннолетия при заполненной дате сохранены. Телефон нормализуется
в принятый моделью формат `+375 (29) XXX-XX-XX`.

Пауза слайдера при фокусе, скрытой вкладке и настройке reduced motion дополняет
обязательную паузу при наведении. Ручная пауза позволяет спокойно читать слайды.

Web Speech API зависит от браузера и наличия голосового движка ОС. Сам факт
поддержки API не гарантирует наличие русского голоса или звукового вывода.

## Быстрый показ на защите

1. Главная: перелистнуть слайды стрелками и пагинацией, открыть ссылку баннера.
2. Войти admin/admin12345, изменить delay, выключить loop, проверить сохранение.
3. Переключить тему и обновить страницу.
4. Сотрудники: 10 записей, страницы по 3, сортировка, поиск «Фролов», карточка.
5. Отметить сотрудников на двух страницах, нажать «Премировать».
6. В форме попробовать `123` и `https://site.ru`, затем `80291112233` и
   `https://site.ru/photo.html`; добавить запись и обновить страницу.
7. Каталог: перелистнуть страницы, изменить размер, показать 3D при наведении.
8. Практикум: создать два поля, изменить атрибуты, обновить, удалить одно поле.
9. Ввести дату взрослого и ребёнка. В задаче учеников показать обе реализации.
10. Прочитать текст, построить график, сохранить PNG; попробовать отрицательный
    диапазон от -4 до -1.2. На главной прокрутить сцену товаров вниз и обратно.

## Проверки

```
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test
python -m pytest -q
node --test tests/lr3-core.test.cjs
```

Дополнительная браузерная проверка (отдельная временная БД, Chrome):

```
pip install -r requirements-browser.txt
python manage.py test tests.browser_checks --noinput
```

Тесты проверяют сохранение темы и полей, слайдер, сортировку/поиск/пагинацию,
добавление в базу, ошибки формы, выбор на разных страницах, график и PNG,
границу совершеннолетия, обе реализации наследования, отсутствие ошибок JS
и горизонтального переполнения при 390×844 и 900×400.
PNG и скриншоты проверки сохраняются в `/tmp/strweb-lr3-qa/`.
Браузерный тест не подтверждает реальное звучание голоса и работу на телефоне.
