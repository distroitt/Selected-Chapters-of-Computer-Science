# ЛР2 HTML и CSS — карта требований

Вариант: зоомагазин PetCare Market. Основа — существующий Django-проект ЛР1. Библиотеки оформления не используются, все стили написаны в `static/style.css`. JavaScript для анимации и прелоадера не используется.

| Требование задания | Где показать и как реализовано |
| --- | --- |
| Селекторы элементов и классов | Весь сайт: `body`, `h1`, `.section`, `.item` |
| Атрибут начинается / заканчивается / равен значению | HTML / CSS: `a[href^="mailto:"]`, `a[href$=".txt"]`, `a[target="_blank"]` |
| AND, потомки и прямые дети | `.button.secondary`, `.news-card h2`, `.site-header > nav` |
| Состояния ссылок и фокус | `:link`, `:visited`, `:hover`, `:active`, `:focus-visible`. Посещённые обычные ссылки фиолетовые; фокус обведён |
| Первый, последний, n-й элемент | История компании, строки и столбцы таблиц: `:first-child`, `:last-child`, `:nth-child` |
| Формы: доступные, обязательные, заблокированные, вне диапазона | `/html-demo/#form`: `:enabled`, `:required`, `:disabled`, `:out-of-range`. Количество 12 при диапазоне 1–10 выделено красным; исправьте значение |
| Флажки и переключатели | Там же: `:checked`, цвет и обводка. Установите флажок или выберите способ ответа |
| Кавычки по языку | `/html-demo/#text`: `q:lang(ru/en/fr)`, свойство `quotes` |
| Первая буква, контекст до/после, маркеры Unicode, выделение | Полная статья: `::first-letter`; HTML / CSS: `.context-note::before/after`, `.paw-list li::marker`; выделите текст для `::selection` |
| Основной шрифт из службы, запасной и семейство | Google Fonts Nunito; Trebuchet MS, Arial, sans-serif. При отсутствии сети работают запасные шрифты |
| Ширина и высота viewport | Запросы `max-width: 820px/560px`, `max-height: 500px` |
| Курсор на кнопках | `cursor: pointer`; заблокированное поле — `not-allowed` |
| Текст: поля, отступы, регистр, абзац, интерлиньяж | Весь сайт: margin/padding, `.eyebrow` text-transform; статьи и политика — text-indent, line-height |
| Капитель, интервалы, переносы, выравнивание | Сертификат и caption: font-variant; бренд: letter-spacing, font-kerning; сертификат: word-spacing; статьи: hyphens, overflow-wrap, text-align |
| Фон сайта | Радиальный градиент и фоновый цвет |
| Каталог CSS Grid | `/products/` и популярные товары главной — `.grid` |
| Круглые партнёры, граница и тень | Главная: `.partner`, размер 180 × 180, border-radius 50%, border и box-shadow |
| Последняя статья и закреплённая навигация | Главная: relative/absolute для статьи и даты; шапка sticky при прокрутке |
| Логотип с трансформацией | `/about/`: rotate и scale, изменение при наведении |
| Сертификат | `/about/`: border-image из SVG, вендорные префиксы, фоновый SVG и градиент, z-index, шрифты и выравнивание. Это оформленный текст, а не картинка сертификата |
| История, реквизиты, медиа | `/about/`: список по годам, моноширинные реквизиты, оформление video; `/html-demo/#media`: audio |
| 7 статей, иллюстрации, краткое описание, кнопка | `/news/`: семь записей в БД через seed_demo, локальные тематические SVG; кнопка «Читать далее» открывает полный текст |
| Обрезка краткого содержания и многоколонный текст | `.news-summary`: overflow hidden + text-overflow ellipsis; `.article-columns`: column-count 2, на узком экране 1 |
| Словарь с датой и раскрывающимся ответом | `/faq/`: оформленные details/summary и дата из БД |
| Контакты Flexbox | `/contacts/`: flex-контейнер списка и flex-карточка каждого сотрудника |
| Политика со своим стилем | `/privacy/`: оформленные разделы, интервалы, отступ первой строки |
| Вакансии float и clear | `/vacancies/`: карточки float left, clear left и очистка контейнера; на телефоне одна колонка |
| Шрифты компонентов формы ключевыми словами | Форма добавления отзыва: `.entry-form input/button` — caption, select — menu, textarea — message-box |
| Действующие и архивные промокоды | `/promos/`: активность учитывает флаг и дату; архив имеет отдельный стиль |
| Списки и таблицы | Списки истории и ухода; таблицы: collapse, пустые ячейки :empty, caption сверху, выравнивание, полосатые строки, выделенный второй столбец |
| Анимация зоомагазина | Главная: три CSS-рыбки меняют координаты X и Y, водоросли колышутся; название появляется после задержки 3 секунды и остаётся |
| Прелоадер вращения внизу | Главная: `.preloader`, keyframes spin; показан отдельным блоком внизу без JS |

## Быстрая демонстрация

1. Главная: подождать четыре секунды, прокрутить страницу, показать партнёров и прелоадер.
2. Каталог: показать сетку и изменить ширину окна.
3. О компании: логотип, история, реквизиты, сертификат.
4. Новости: семь карточек, обрезанное описание, полный текст в колонках.
5. Контакты и вакансии: Flexbox и float/clear.
6. HTML / CSS: цитаты, маркеры, выделение, пустая ячейка, состояния формы.
7. Отзывы: войти под `buyer` / `buyer12345`, открыть форму добавления.

При включённом системном уменьшении движения анимация отключается через `prefers-reduced-motion`, а название видно сразу.

## Результаты проверки

- `python manage.py check`: ошибок конфигурации нет.
- `python manage.py makemigrations --check --dry-run`: изменений схемы БД нет.
- `python manage.py test`: 20 тестов прошли.
- `python -m pytest -q`: 24 теста прошли (одно предупреждение Django о будущем значении схемы URLField).
- Chrome: 13 страниц на размерах 1440×1000, 390×844 и 900×400 — 39 успешных проверок HTTP 200 и отсутствия горизонтального переполнения страницы.
- Отдельно проверены появление названия, изменение координат X/Y рыбок, закрепление шапки при прокрутке, семь карточек новостей, активный/архивный купоны и поле вне диапазона.
- Просмотрены снимки главной, сертификата, новостей и контактов. Фотографии сотрудников сохранены локально; источник демо-портретов — Pravatar. Портреты служат иллюстрациями, имена сотрудников вымышлены.

Это локальные проверки проекта и браузера; внешняя W3C-валидация не выполнялась. Мультимедиа ЛР1 и Google Fonts загружаются из сети.
