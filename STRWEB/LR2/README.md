# Лабораторная работа 2. HTML и CSS. Зоомагазин

ЛР2 выполнена на базе проекта ЛР1: собственные адаптивные CSS-стили без Bootstrap, каталог на Grid, контакты на Flexbox, вакансии с float/clear, оформленный сертификат, семь статей и CSS-анимация аквариума с прелоадером.

Карта всех требований и порядок показа на защите: [docs/LR2_CHECKLIST.md](docs/LR2_CHECKLIST.md).

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
python manage.py runserver
```

После запуска откройте `http://127.0.0.1:8000/`. Демо-аккаунт покупателя: `buyer` / `buyer12345`; администратора: `admin` / `admin12345`.

Страница `/html-demo/` собирает примеры тегов из задания: списки, таблицу с `headers`, форму с HTML-валидацией, iframe, видео и аудио.

## Промокоды

Покупатель видит действующие и архивные промокоды на странице `/promos/`.
При покупке товара на странице `/products/<id>/buy/` можно ввести код в поле `Промокод`.
Сайт проверяет, что код существует, активен и не просрочен, после чего сохраняет его в продаже и пересчитывает итоговую сумму.

В демо-данных доступен промокод `PET10`.

## Остатки товаров

Количество товара на складе не хранится отдельным полем. Оно считается по фактическим операциям:

```text
остаток = сумма закупок товара - сумма проданных единиц товара
```

Закупки через `SupplyPurchase.quantity` пополняют склад, а продажи через `SaleItem.quantity` уменьшают остаток. Пользователь не может оформить покупку, если товара нет на складе или запрошенное количество больше остатка.

## Логирование

Уровень логирования берется из переменной окружения `LOG_LEVEL`, по умолчанию используется `INFO`.
Логи приложения `shop` пишутся в консоль и в `logs/petshop.log`.

Сейчас логируются регистрация, добавление отзывов, покупка товара, применение промокода, ошибки покупки, CRUD-операции сотрудников с товарами/поставщиками/закупками, обращения к защищенным API и сбои внешних API.
